# 桂林 3D 山水模拟城市 (Guilin 3D City Simulation)

基于 **Three.js** 与现代前端技术构建的中国桂林山水 3D 模拟城市。“桂林山水甲天下”——本项目精细还原了两江四湖水系、标志性喀斯特峰林地标与城市风貌，并支持昼夜光照、气象变化及动态交通模拟。

---

## 🌟 核心特色与景观还原

1. **两江四湖水系与喀斯特地貌**
   - **水系网络**：真实还原漓江、桃花江、杉湖、榕湖。水面采用自定义 GLSL Shader，呈现水纹微波、天空折射与夜间光影倒影。
   - **喀斯特地貌**：精细建模象鼻山（含水月洞与山顶普贤塔）、独秀峰、伏波山、叠彩山、七星岩群峰、穿山与塔山等。

2. **标志性人文古建与现代城区**
   - **日月双塔**：杉湖中的九级金塔（日塔）与七级银蓝琉璃塔（月塔），包含水下玻璃连廊。
   - **靖江王府**：独秀峰下的明代藩王城垣、承运门与殿宇。
   - **古南门与千年大榕树**：榕湖畔的历史名胜与湖心亭。
   - **东西巷与正阳步行街**：青砖灰瓦岭南古街区。
   - **桥梁群**：解放桥、阳桥、榕湖玻璃桥等跨江跨湖拱桥。

3. **动态生态与城市运行模拟**
   - **水上航线**：漓江竹筏与画舫游船巡游。
   - **道路交通**：主干道车流与观光巴士，夜间车灯流光。
   - **自然生态**：盘旋飞翔的白鹭、漫天微拂的桂花花瓣与烟雨粒子效果。

4. **交互控制与规划建造模式**
   - **昼夜与光照**：0:00 - 24:00 无级调光，预设晨雾、晴日、日落、夜景模式。
   - **气象系统**：晴朗、水墨晨雾、烟雨漓江。
   - **互动规划**：可在空地放置中式亭台、岭南民居、现代建筑或种植桂花林。

## 🚀 本地运行

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务
npm run dev

# 3. 构建生产版本
npm run build

# 4. 本地预览生产构建
npm run preview
```
